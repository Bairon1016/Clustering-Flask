Descripción

El dataset utilizado contiene información sobre casos positivos de COVID-19 reportados en Colombia durante el período comprendido entre agosto de 2020 y septiembre de 2021. Este conjunto de datos está compuesto por 1,200 registros y 12 variables que describen diferentes aspectos clínicos, demográficos y geográficos de los pacientes.

Variables del Dataset

  • Fecha_Reporte: Fecha en la que se reportó oficialmente el caso positivo.
  • Departamento: Departamento colombiano donde se registró el caso.
  • Ciudad/Municipio: Municipio específico de residencia del paciente.
  • Edad: Edad del paciente al momento del diagnóstico.
  • Sexo: Género del paciente (F: Femenino, M: Masculino).
  • Tipo_Contagio: Clasificación del contagio (Comunitaria o Relacionado).
  • Ubicación: Lugar donde el paciente recibió atención o aislamiento (Casa, Hospital, Fallecido, etc.).
  • Estado: Condición clínica del paciente (Leve, Moderado, Grave, Fallecido).
  • Recuperación: Estado final del paciente (Recuperado o Fallecido).
  • Inicio_Sintomas: Fecha en la que el paciente comenzó a presentar síntomas.
  • Fecha_Recuperacion: Fecha en la que el paciente fue dado de alta o confirmado como recuperado.
  • Tipo_Recuperacion: Método utilizado para confirmar la recuperación (PCR o Tiempo).

Este dataset proviene de registros oficiales de salud pública y representa una muestra significativa de la evolución de la pandemia en diferentes regiones del país, permitiendo realizar análisis multivariados que contribuyan a una mejor comprensión del fenómeno epidemiológico.

Justificación Dataset

La selección de este dataset se basa en su relevancia para el análisis epidemiológico y su potencial para generar conocimiento aplicable en contextos de salud pública. A continuación, se presentan las razones que justifican su utilización:

Representatividad geográfica y temporal

El dataset incluye casos provenientes de múltiples departamentos y municipios de Colombia, abarcando un período crítico de la pandemia. Esto permite identificar diferencias regionales en el comportamiento del virus y los perfiles de pacientes afectados.

Diversidad de variables clínicas y demográficas

La presencia de variables como edad, sexo, tipo de contagio, ubicación del paciente y estado de recuperación facilita la identificación de patrones complejos mediante técnicas de clustering. Estas agrupaciones pueden revelar perfiles de riesgo, grupos etarios más vulnerables y condiciones asociadas a mayor mortalidad.

Aplicabilidad del algoritmo K-Means

El algoritmo K-Means es particularmente efectivo para identificar grupos naturales dentro de conjuntos de datos numéricos. Al transformar variables categóricas mediante técnicas de codificación y normalizar los datos, se garantiza que el modelo pueda detectar similitudes entre pacientes basándose en múltiples dimensiones simultáneamente.

Utilidad para la toma de decisiones

Los resultados obtenidos del clustering pueden ser utilizados para segmentar poblaciones objetivo en campañas de vacunación, identificar zonas de alta incidencia que requieran intervención prioritaria, y diseñar estrategias diferenciadas de atención según el perfil de cada cluster.

Disponibilidad y calidad de los datos

Este dataset cuenta con información estructurada y completa, lo que minimiza la necesidad de imputación masiva de valores faltantes y permite realizar un análisis robusto y confiable.

En conjunto, estas características hacen del dataset una herramienta valiosa para explorar el potencial del análisis de clustering en el ámbito de la epidemiología, proporcionando una información y un análisis que contribuyen al control y mitigación de futuras crisis sanitarias.

K-Means Clustering

K-Means Clustering es un algoritmo de aprendizaje no supervisado utilizado para agrupar datos según características similares. Su objetivo es dividir un conjunto de registros en diferentes grupos llamados clusters, logrando que los datos dentro de cada grupo sean lo más parecidos posible entre sí y diferentes de los demás grupos.

A diferencia de los algoritmos supervisados, K-Means no requiere etiquetas previas ni variables objetivo. El modelo identifica patrones automáticamente a partir de las características de los datos.

Funcionamiento del Algoritmo

1. Selección de K

Se define la cantidad de clusters a generar. En este proyecto se utilizó K = 3 mediante el método del codo.

2. Inicialización

El algoritmo selecciona centroides iniciales que representan el centro de cada grupo.

3. Asignación

Cada registro se asigna al centroide más cercano utilizando distancia euclidiana.

4. Recalculo

Los centroides se actualizan utilizando el promedio de los datos pertenecientes a cada cluster.

5. Iteración

El proceso se repite hasta alcanzar convergencia y estabilizar los grupos.


Variables Utilizadas

  • Dias_Recuperacion

Estas variables permitieron agrupar pacientes según similitudes relacionadas con la edad y el tiempo de recuperación frente al COVID-19.

El objetivo principal del modelo fue identificar patrones dentro de los casos positivos de COVID-19 en Colombia.

  • Detectar grupos con características similares.
  • Analizar diferencias en tiempos de recuperación.
  • Relacionar edades con comportamiento de recuperación.
  • Visualizar patrones presentes en los datos.
  • Interpretar perfiles de pacientes.

Gracias al clustering fue posible realizar un análisis exploratorio sin necesidad de clasificaciones previas.


Conclusión

El algoritmo K-Means permitió agrupar automáticamente pacientes con COVID-19 según similitudes en edad y tiempo de recuperación. Los resultados obtenidos facilitaron la identificación de patrones relevantes y su representación mediante gráficas y tablas dentro de la aplicación Flask.

Método del Codo

Para determinar el número adecuado de clusters en el modelo K-Means, se utilizó el método del codo, una técnica ampliamente utilizada para identificar el valor óptimo de K.

El método consiste en ejecutar K-Means múltiples veces utilizando diferentes cantidades de clusters y calcular la inercia para cada valor de K.

La inercia representa la suma de distancias entre cada punto y el centroide de su cluster correspondiente. Mientras menor sea la inercia, mejor agrupados se encuentran los datos.

Sin embargo, la inercia siempre disminuye al aumentar la cantidad de clusters. Por esta razón, se busca el punto donde la reducción comienza a estabilizarse, conocido como el “codo”.


Gráfica del Método del Codo


En este proyecto se evaluaron distintos valores de K y se observó que el cambio más significativo ocurre hasta K = 3. A partir de este punto, la disminución de la inercia es mucho menor.

  • Permite obtener grupos diferenciados claramente.
  • Reduce la variabilidad interna de los clusters.
  • Evita crear grupos innecesarios.
  • Facilita la interpretación de resultados.

Por esta razón, se seleccionó K = 3 como número óptimo de clusters.
